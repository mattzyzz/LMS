## BACKEND

Создай или расширь API. Сначала проверь что уже есть в проекте,
не дублируй существующее.

### Модели данных
- Department: id, name, parentId (вложенность отдела внутри департамента),
  headEmployeeId (руководитель), order (порядок сортировки)
- Employee — добавь если отсутствует: departmentId, phone,
  employeeNumber, managerId, status (online/offline/vacation),
  vacationUntil

### Эндпоинты
GET    /api/org-structure            — дерево целиком
POST   /api/departments              — создать департамент или отдел
PATCH  /api/departments/:id          — переименовать, сменить руководителя
DELETE /api/departments/:id          — удалить (только если нет сотрудников)
PATCH  /api/departments/:id/move     — переместить (drag and drop, новый parentId + order)
PATCH  /api/employees/:id/department — перевести сотрудника в другой отдел

## FRONTEND

### Дерево структуры (точно по скриншоту)
- Иерархия: Департамент → Отдел → Сотрудник
- Кнопки [+]/[−] слева — круглые серые, раскрывают и скрывают узел
  с плавной анимацией ~200ms
- Под названием каждого узла серая подпись:
  "Директор департамента — Имя Фамилия" или "Руководитель не назначен"
- Сотрудник: цветной аватар с инициалами, цветная точка статуса (
  синяя = онлайн, серая = офлайн), имя и должность
- Клик на сотрудника — inline-карточка под строкой (не модалка):
    - ФИО полностью, должность
    - Бейдж если в отпуске: "В отпуске до дд.мм.гггг" (синий фон)
    - Email, телефон, табельный номер
    - "Руководитель — ФИО"
    - Кнопки: [👤 Посмотреть профиль] и [✉ иконка конверта]
    - Одновременно открыта только одна карточка

### Управление структурой (только для роли admin/hr)
- Кнопка "Добавить департамент" вверху страницы
- При наведении на любой узел — кнопка [...] с меню:
    - Добавить отдел внутрь
    - Назначить руководителя
    - Переименовать
    - Удалить
- Drag and drop:
    - Перетаскивание сотрудника из одного отдела в другой
    - Перетаскивание отдела внутри департамента (изменить порядок)
    - Визуальная подсветка зоны куда перетаскивают
    - Сохранение через API сразу после drop (optimistic update)
- Обычный сотрудник видит структуру без возможности редактирования

### Статистика справа (уже есть — не трогай вёрстку, только подключи реальные данные):
- Количество сотрудников в компании
- Количество отделов и департаментов
